# 视觉追踪使用说明

视觉追踪按仓库职责拆分：

- `vision_tracker.py`：纯状态机，接收视觉结果 dict 并返回左右轮命令，
  不持有相机或电机。
- `rpi-yolo-pi4-int8-lto-8fps/`：YOLO 视觉运行时，`VisionClient.get_control()`
  产出状态机的输入契约。
- `dev/vision_tracker.py`：真机独立测试与同步 CSV 采集。
- `vision_tracker_pack/`：分享给队友的逻辑包（精简 config + 契约 README）。

## PC 单元测试

```powershell
python -m unittest discover -s tests -t . -v -p test_vision_tracker.py
```

覆盖：居中直行、左右小转差速、大转滞回、无效帧停车、轮速死区下限。

## 真机独立测试

```powershell
python3 dev/vision_tracker.py
```

默认不启用电机，只跑 YOLO + 状态机并把每个新视觉结果落盘到
`data/vision_tracker_<时间戳>.csv`（含 `offset_x`、状态、左右轮命令等列）。

```powershell
python3 dev/vision_tracker.py --drive --seconds 60
```

`--drive` 启用电机：启动前把车放平整空地、确保周围无人无障碍，输入 `DRIVE`
确认后才下发电机会命令。可选 `--hz`（默认 50）、`--max-age-ms`（默认 450，
超过约 3 个视觉帧周期无新结果立即停车）、`--motor-invert` / `--no-motor-invert`、
`--motor-swap` / `--no-motor-swap`（默认取 config 的 `CHASSIS_*`）。

## 给队友的包

`vision_tracker_pack/` 内含 `vision_tracker.py` + 精简 `config.py` + README
（输入/输出契约、状态机语义、接线示例、参数重标说明），见包内 README。
