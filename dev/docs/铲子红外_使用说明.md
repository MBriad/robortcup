# 铲子红外使用说明

铲子底下 2 路模拟红外（config `SHOVEL_IR_CHANNELS`：左=adc4、右=adc5），防掉落用。
换车后只需**接线核对 + 悬空/台内两组采集重算阈值**。

## 接线核对

```bash
python3 dev/shovel_tool.py scan
```

看全 10 路 ADC（L/R 标记当前 config 通道）。4 个姿态各停 3~5 秒确认：

| 姿态 | 参考值（新车 2026-08-15 实测） |
|---|---|
| 台内（铲子平放台面） | adc4≈20、adc5≈1244 |
| 悬空（铲子伸出台面） | adc4≈1294、adc5≈1454 |
| 手挡左传感器 | adc4 明显变化 |
| 手挡右传感器 | adc5 明显变化 |

几百以上的变化才算响应，20↔70 的抖动是底噪。若某通道不响应，先查插头。

**注意新车极性反了**：悬空=信号高、台内=信号低（旧车相反），
防掉落判据按「高于 ENTER 触发、低于 CLEAR 收回」写。

## 采集与重算阈值

```bash
python3 dev/shovel_tool.py collect   # 选 1=悬空（铲子伸出台面），5~10 秒，姿态保持稳定
python3 dev/shovel_tool.py collect   # 选 2=台内（铲子平放台面），5~10 秒
python3 dev/calibrate_shovel.py      # 重算 → data/shovel_model.csv，写回 config SHOVEL_HANG_*
```

CSV 拷回 PC 后用 Excel 看完先关掉再跑 calibrate（文件被占用会读取失败）。

## 防掉落真机测试

```bash
python3 dev/shovel_guard.py --active   # 推东西模式模拟：铲子悬空应停车→3帧确认→倒车→收回停
```

台内全程应保持 IDLE 不动电机；悬空第一帧即停车。

生产运行 `main.py` 时，前灰度进入 `zone < 0.76` 的预热边缘会提前启用 9 帧
中值滤波。铲子仍在台内时不接管电机；铲子悬空后优先于巡台停车并倒车，掉台
回归状态机仍保持最高优先级。
