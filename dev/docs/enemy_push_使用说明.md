# 敌人搜索与推动测试

生产比赛只运行根目录 `main.py`。本工具只运行敌人状态机，单独验证六路数字
红外、定角转向和敌人推动。后台视觉保持运行并写入 CSV，但不参与电机控制；
巡台、回台和 hunt 都不会创建。

## 文件职责

- `enemy_push.py`：纯状态机，不导入硬件驱动。
- `dev/enemy_push.py`：真机传感器读取、后台 YOLO、电机执行与 CSV。
- `config.py`：推动速度、分级限速、退回与冷却参数。
- `tests/test_enemy_push.py`：PC 状态机测试。

## 无限真机测试

```bash
python3 dev/enemy_push.py --label enemy_integration --seconds 0 --drive
```

输入 `DRIVE` 后启用电机，按 `Ctrl+C` 停止；CSV 默认写入 `data/`。

所有可调参数集中在 `config.py` 的 `ENEMY_*`：推动/慢档速度、灰度阈值、
退回/暂停/冷却时长、五个红外方位转角、正后首次转向方向，以及 dev 默认
频率、运行时长和日志目录。

## 仲裁规则

1. 视觉只在后台采集，不阻止或产生任何电机命令。
2. 正前红外触发时，开始推动敌人。
3. 正前空闲时，左前/右前/左后/右后/正后按 45°/135°/180°定角转向。
4. 转向途中正前红外触发，立即切入推动。
5. 敌人模块自身的灰度限速、后路保护和铲子悬空收回仍然生效。

## 推荐真机顺序

每次只放一个目标并单独保存 CSV：

1. 正前红外触发：应进入 `PUSH`。
2. 左前/右前触发：应朝对应方向转 45°。
3. 左后/右后触发：应朝对应方向转 135°。
4. 正后触发：应转 180°。
5. 推到铲子悬空：应停车、倒车收回，不能继续前冲。
