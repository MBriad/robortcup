# 掉台回归(倒车)参数调整说明

掉台回归流程：掉台触发（四路灰度全暗）→ 六路数字红外定转向 → 转 90°/180° →
大力前冲撞墙（贴墙信号 ≥1060 停）→ 左右矫正（diff 区间）→ 倒车脱离（前头数字红外
熄灭停）→ SAFE_STOP。参数全部在 config.py，**改完直接重跑 dev/reentry.py 验证**。

## 台架测试：强制触发（--force-trigger）

车没真掉台也能把整条流程跑一遍：

```bash
python3 dev/reentry.py --force-trigger
```

- **原理**：启动后在 WAIT 状态把掉台计数直接拉到确认帧数，强制触发**一次**；
  之后的 fall 电平仍按真实灰度判断。
- **用途**：台架架空轮子，验证状态迁移（分派→转向→冲墙→矫正→倒车→SAFE_STOP）
  与各段电机方向/速度。
- **条件**：触发瞬间需要某路数字红外亮（如车头对墙 → 前头 io0 亮直接进矫正），
  否则进 IR_WAIT；此时若车还在台上（灰度正常），下一帧就回 WAIT，等于没触发。
  所以台架上要让前头（或侧向）红外对着墙。
- **注意**：进入转向/冲墙/矫正/倒车后流程会一路走完，不受灰度影响；
  真实掉台测试不要传此参数（等灰度全暗自然触发）。
- 台架不想真撞墙可临时把 `REENTRY_APPROACH_SPEED / REENTRY_REVERSE_SPEED`
  调小（如 400），但注意后果：冲墙可能 2 秒内够不着墙（贴墙判定到不了 1060）、
  倒车退距不够前头数字红外不熄灭（探测 ~30cm）→ 都会超时 SAFE_STOP。
  这只是台架预期行为，正式速度 700/550。

## 症状 → 改哪个参数

| 症状 | 参数 | 调整方向 |
|---|---|---|
| 贴墙了还猛冲（堵转满 2 秒） | `REENTRY_APPROACH_TOUCH_SIGNAL` | **调低**（现在 1060，贴墙实测 p99≈1363） |
| 离墙老远就提前停 | 同上 | **调高**（别高于贴墙实测值 1363） |
| 冲墙太猛/太慢 | `REENTRY_APPROACH_SPEED` / `APPROACH_TIMEOUT` | 速度 ≥400（电机死区）；冲不到位调高速度或超时 |
| 矫正时原地乱转不停（3 秒超时） | `IR_ALIGNMENT_DIFF_LOW / DIFF_HIGH` | 区间错才会乱转：先查 `IR_CHANNELS` 左右通道有没有标反（标反 diff 符号就反，矫正方向全错）；区间需重采（见下） |
| 矫正方向反了 | `IR_CHANNELS` | 用 `dev/ir_tool.py scan --mapped` 手挡确认左=adc7、右=adc6；换车通道变了改这里 |
| 矫正太快判「正对」/老判不正 | `IR_ALIGNMENT_CONFIRM` | 正对确认帧数，防抖：老误判调高，太慢调低 |
| 信号明明有却总走「冲墙」分支 | `IR_ALIGNMENT_SIGNAL_MIN` | 滤波后峰值 < 296 判信号弱；传感器老化了调低，但最好重采数据再定 |
| 倒车退得不够/退过头 | `REENTRY_REVERSE_TIMEOUT` | 倒车兜底时长：退出墙的距离不够调高，过头调低 |
| 倒车太快/太慢 | `REENTRY_REVERSE_SPEED` | 现在 = `PATROL_RECOVER_SPEED`(550)，与巡台恢复共用；要分开调就改成独立数值 |
| 倒车方向反了 | `CHASSIS_MOTOR_INVERT` | 不动驱动层；改 config 的电机方向修正 |
| 前头数字红外还没离墙就灭（倒车提前停） | 查数字红外接线/位号 | `dev/digi_ir_tool.py scan` 核对 `DIGI_IR_BITS`（前=io0）；是硬件挡光就调传感器 |
| 掉台误触发/漏触发 | `REENTRY_FALL_CONFIRM` | 全暗连续帧数：误触发调高，漏触发调低 |
| 掉台后转 90°/180° 角度不准 | `MOTOR_TURN_CALIBRATION` | 与巡台共用；用 `dev/turn_tool.py --angle N` 重采该角度速度/时长 |

## 参数位置与当前值（config.py）

**掉台回归段 `REENTRY_*`**（默认值，新车 2026-08-15）：

| 参数 | 值 | 作用 |
|---|---|---|
| `REENTRY_FALL_CONFIRM` | 3 | 掉台确认帧数 |
| `REENTRY_CORRECT_TURN_SPEED` | 400 | 矫正原地转速（=PATROL_MIN_ACTIVE_SPEED） |
| `REENTRY_CORRECT_TIMEOUT` | 3.0 | 矫正超时 → SAFE_STOP |
| `REENTRY_APPROACH_SPEED` | 700 | 大力前冲速度 |
| `REENTRY_APPROACH_TIMEOUT` | 2.0 | 冲墙兜底时长 |
| `REENTRY_APPROACH_TOUCH_SIGNAL` | 1060.0 | 贴墙判定信号 |
| `REENTRY_REVERSE_SPEED` | 550 | 倒车速度（=PATROL_RECOVER_SPEED） |
| `REENTRY_REVERSE_TIMEOUT` | 3.0 | 倒车兜底时长 |

**矫正判定段 `IR_ALIGNMENT_*`**（来源 data/front_adc_model.csv，新车 08-15 重采）：

| 参数 | 值 | 作用 |
|---|---|---|
| `IR_ALIGNMENT_FILTER_WINDOW` | 9 | 中值滤波窗口 |
| `IR_ALIGNMENT_DIFF_LOW` | -75.1 | diff 低于此 = 左偏需右转 |
| `IR_ALIGNMENT_DIFF_HIGH` | 63.5 | diff 高于此 = 右偏需左转 |
| `IR_ALIGNMENT_CONFIRM` | 3 | 连续正对帧数 |
| `IR_ALIGNMENT_SIGNAL_MIN` | 296.0 | 低于此 = 信号弱走冲墙分支 |

## 阈值怎么重标（换车/场地变了）

```bash
python3 dev/ir_tool.py collect      # 采 正对墙居中位置 / 正对墙(贴墙) / 正对墙最远 / 左偏居中位置 / 右偏居中位置
python3 dev/calibrate_front_adc.py  # 重算 IR_ALIGNMENT_*；贴墙阈值取贴墙 p99 与居中 p99 中点
python3 dev/turn_tool.py --angle 90 # 转向角度不准时重采（左右分开）
```

详见 dev/docs/前头红外_使用说明.md。**参数只在 config.py 改，驱动层不动。**
