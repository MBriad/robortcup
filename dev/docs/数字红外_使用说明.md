# 数字红外使用说明

六路数字红外(左前/左后/右前/右后/前/后)用于掉台回归的方向判断:
掉台后靠这六路判断「哪边对着台」来定转向方向。换车后只需**接线核对**,无 CSV 采集。

## 核对步骤

```bash
python3 dev/digi_ir_tool.py scan
```

逐个挡住六个传感器,看对应 **io 位**是否翻 0↔1(ACTIVE_LEVEL=0,低电平有效,
挡到位翻 0)。

## 当前映射(config.py DIGI_IR_BITS,新车 2026-08-14 scan 实测)

| 传感器 | 对应位 |
|---|---|
| 前 front | io0 |
| 左前 left_front | io3 |
| 左后 left_rear | io1 |
| 右前 right_front | io2 |
| 右后 right_rear | io4 |
| 后 rear | io6 |

## 对不上怎么办

哪路挡了哪个 io 变,记录下来(如「挡左前,io3 变」),修改 config.py 的
`DIGI_IR_BITS` 对应条目即可,不要动驱动层。

## 可选:采集原始数据

```bash
python3 dev/digi_ir_tool.py collect --hz 50 --out data/digi_ir_时间.csv
```

CSV 同时存原始掩码(mask, io0~io7)和六路映射状态
(left_rear / left_front / right_rear / right_front / rear / front / valid),
排查接线问题用。

## 注意事项

- 掉台回归的转向方向完全依赖这六路接线正确性,接线错会朝反方向转,**上真机前必核**。
- 数字红外没有标定阈值,只有接线映射;核对一致即完成。
