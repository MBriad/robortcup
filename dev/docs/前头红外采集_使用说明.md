# 前头红外采集使用说明

前头两路模拟红外(左 adc5 / 右 adc4)用于掉台回归的对墙矫正与贴墙检测。
换车后重采固定姿态数据,文件名为标定与单测的固定名。

## 第 0 步:接线复核

```bash
python3 dev/ir_tool.py scan
```

显示全 10 路 ADC(L/R 标记前头两路)。用手挡左/右前头红外,确认读数对得上
(`scan --mapped` 可看映射后的 left/right/diff)。对不上先排查接线。

## 第 1 步:采集固定姿态

车头对着一面墙,摆固定姿态后开跑,采 5~15 秒 Ctrl+C 停止。四个必需文件:

```bash
# 正对墙、离墙居中距离(标定必需:center_middle)
python3 dev/ir_tool.py collect --hz 50 --out data/正对墙且离墙居中位置.csv

# 左偏约 20°、离墙居中距离(标定必需:left_bias)
python3 dev/ir_tool.py collect --hz 50 --out data/左偏20度且离墙居中位置.csv

# 右偏约 20°、离墙居中距离(标定必需:right_bias)
python3 dev/ir_tool.py collect --hz 50 --out data/右偏20度且离墙居中位置.csv

# 正对墙、离墙最远(标定必需:center_far,定信号强度下限)
python3 dev/ir_tool.py collect --hz 50 --out data/正对着墙且距离墙最远.csv
```

可选(动态转场,文件名含「从90度」会被识别为动态段):

```bash
python3 dev/ir_tool.py collect --hz 50 --out data/车子左偏且从90度往正中间转且离墙居中位置转.csv
python3 dev/ir_tool.py collect --hz 50 --out data/车子右偏且从90度往正中间转且离墙居中位置转.csv
```

## 第 2 步:拷回 PC 后标定

```bash
python3 dev/calibrate_front_adc.py
```

输出 `data/front_adc_processed.csv`(滤波明细)、`front_adc_summary.csv`(分组统计)、
`front_adc_model.csv`(建议值:diff_low / diff_high / signal_min 等)。核对后写回
config.py 的 `IR_ALIGNMENT_*` 与 `REENTRY_APPROACH_TOUCH_SIGNAL`,再跑
`python3 -m unittest discover -s tests -t . -v` 核对一致性。

## 注意事项

- 四个必需姿态缺一不可,标定会报错列出缺哪个。
- 「左偏/右偏/正对」三组的滤波区间必须不重叠,重叠说明偏转角度没拉开或距离没固定,
  需要重采。
