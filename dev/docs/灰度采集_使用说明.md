# 灰度采集使用说明

换车/换场地后重采灰度数据的操作流程。所有文件名必须与旧数据一致
(`calibrate_gray.py` 和单测按固定文件名读取)。

## 第 0 步:接线复核

```bash
python3 dev/gray_tool.py scan
```

依次用手挡 front / rear / left / right 四个传感器,确认读数是**对应位置**在变化
(挡哪路哪路变)。位置对不上先别采,记录 scan 结果排查接线。

若接线插反(如左右对调),交换 config.py `GRAY_CHANNELS` 对应通道即可,不要改驱动层;
改完重跑 scan 复核。当前新车状态:左右插反,config 已交换。

## 第 1 步:采集 24 个文件

每条命令跑起来后,车按姿态动起来,采够 5~15 秒按 **Ctrl+C 停止**
(也可加 `--dur 10` 定时)。

### A. 基础姿态(2 个)

```bash
python3 dev/gray_tool.py collect --hz 50 --out data/四个同黑.csv        # 四个灰度都压在纯黑地面
python3 dev/gray_tool.py collect --hz 50 --out data/四个同白.csv        # 四个灰度都压在白边/白区
```

### B. 沿边与轴线行进(8 个)

```bash
python3 dev/gray_tool.py collect --hz 50 --out data/边缘容易掉台.csv
python3 dev/gray_tool.py collect --hz 50 --out data/竖向边缘.csv        # 沿台竖向边缘行进
python3 dev/gray_tool.py collect --hz 50 --out data/竖向边缘2.csv       # 同上,第二趟
python3 dev/gray_tool.py collect --hz 50 --out data/边缘.csv            # 沿台边走
python3 dev/gray_tool.py collect --hz 50 --out data/边缘2.csv           # 同上,第二趟
python3 dev/gray_tool.py collect --hz 50 --out data/中轴.csv            # 沿场中轴走
python3 dev/gray_tool.py collect --hz 50 --out data/中轴2.csv           # 第二趟
python3 dev/gray_tool.py collect --hz 50 --out data/对角轴.csv          # 沿对角轴走
python3 dev/gray_tool.py collect --hz 50 --out data/对角轴2.csv         # 第二趟

python3 dev/gray_tool.py collect --hz 50 --out data/边缘希望激活铲子.csv 
```

### C. 武字中心区(4 个)

```bash
python3 dev/gray_tool.py collect --hz 50 --out data/武字数据.csv            # 武字区绕行
python3 dev/gray_tool.py collect --hz 50 --out data/武字数据逆时针.csv      # 反向绕行
python3 dev/gray_tool.py collect --hz 50 --out data/武字中间旋转2圈.csv        # 武字中间原地转 2 圈
python3 dev/gray_tool.py collect --hz 50 --out data/武字中间逆时针旋转2圈.csv  # 反向转 2 圈
```

### D. 更内环四朝向(4 个)

```bash
python3 dev/gray_tool.py collect --hz 50 --out data/更内环侧向移动车头朝武字方向.csv
python3 dev/gray_tool.py collect --hz 50 --out data/更内环侧向移动车头朝武字反方向.csv
python3 dev/gray_tool.py collect --hz 50 --out data/更内环平行移动车头朝内.csv
python3 dev/gray_tool.py collect --hz 50 --out data/更内环平行移动车头朝外.csv
```

### E. 内环(4 个,存档备查——当前 calibrate_gray.py 不读取这组)

```bash
python3 dev/gray_tool.py collect --hz 50 --out data/内环平行移动.csv
python3 dev/gray_tool.py collect --hz 50 --out data/内环平行移动车头朝外.csv
python3 dev/gray_tool.py collect --hz 50 --out data/内环侧向移动车头朝武字方向.csv
python3 dev/gray_tool.py collect --hz 50 --out data/内环侧向移动车头朝武字反方向.csv
```

### F. 掉台测试文件(2 个)

```bash
python3 dev/gray_tool.py collect --hz 50 --out data/掉台四个灰度.csv          # 车掉台状态(四个灰度都在台外黑地面)
python3 dev/gray_tool.py collect --hz 50 --out data/掉台四个灰度比较脏.csv     # 同上,灰度脏一点再采一次
```

## 第 2 步:拷回 PC 后标定

24 个 CSV 拷回 PC 仓库 `data/` 后:

```bash
python3 dev/calibrate_gray.py
```

输出 `data/gray_model.csv`(模型)与 `data/gray_model_summary.csv`(回放摘要),
核对摘要后把参数写回 config.py 的 `GRAY_*` 系列,再跑
`python3 -m unittest discover -s tests -t . -v` 核对一致性。
