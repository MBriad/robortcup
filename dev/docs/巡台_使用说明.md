# 灰度闭环巡台使用说明

巡台实现已经按仓库职责拆分：

- `ring_patrol.py`：纯状态机，只接收四路灰度数据并返回左右轮命令。
- `gray.py`：灰度注入、清洗、滤波和风险模型。
- `config.py`：灰度标定、转向表和巡台参数。
- `dev/ring_patrol.py`：PC CSV 回放、真机独立测试和日志落盘。
- `main.py`：生产比赛入口，负责掉台回归、铲子保险与巡台的仲裁。

## 行为流程

1. 台面内直行巡航：`zone_score >= 1.10` 时速度为 `(450, 450)`，否则为
   `(400, 400)`。
2. 前灰度 `zone < 0.76` 时立即进入预热边缘：启用铲子红外滤波，并直线后退
   0.6 秒。阈值位于 `data/边缘希望激活铲子.csv` 与内环安全数据之间。
3. 后退完成后按左右分开的转向标定原地转 135 度。
4. 转向完成后以 400 速度向前回中 1.5 秒；达到释放线后恢复巡航，否则重新
   执行退离和转向。
5. 转向或回中期间出现单路深暗时，立即回到退离阶段，不进入永久停车状态。
6. 原地转向或向前回中时，若一侧连续三帧进入暗区且与另一侧差值过大，判定
   车身斜压白边，立即重新退离，禁止继续向危险方向移动。转向结束准备前进时
   会先检查一次滤波后的侧向风险，已经斜压边缘则不会下发前进命令。

## PC 回放

```powershell
python dev/ring_patrol.py --replay data/patrol_20260814_200518.csv
```

回放不会导入或控制硬件，会打印状态迁移、完整循环检查以及电机指令范围检查。
静态采集 CSV 没有真实运动反馈，可能不会形成完整循环，此时退出码 1 属预期；
完整循环判据应使用真机巡台日志。

## 真机独立测试

```powershell
python3 dev/ring_patrol.py --hz 50 --seconds 60
```

启动前必须输入 `PATROL`。仅在已经完成外部安全措施时才使用 `--yes` 跳过确认。
默认日志保存到 `data/patrol_<时间戳>.csv`。

## 当前已知风险

- 新车压白边实测读数约为 800-900，低于现有 `GRAY_WHITE_ENTER` 1560 以上的
  标定值，`WHITE_ESCAPE` 通路需要重新采集白边数据后再标定；当前由斜压边缘
  的左右灰度差保护 `patrol_20260816_091726.csv` 中的掉台姿态。
- 内环斜向压上浅色边缘时，四路灰度的区分特征有限。当前直接使用前灰度预热
  和提前离边；若真机仍掉台，需要继续采集带事件标记的巡台日志。
