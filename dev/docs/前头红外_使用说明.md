# 前头红外使用说明

前头 2 路模拟红外（config `IR_CHANNELS`：左=adc7、右=adc6，新车 2026-08-15 scan 实测），
掉台回归用：冲墙贴墙判定（APPROACH_TOUCH_SIGNAL）+ 左右矫正（IR_ALIGNMENT_*）。
换车后需**接线核对 + 5 个固定姿态采集重算阈值**。

## 接线核对

```bash
python3 dev/ir_tool.py scan --mapped   # left/right/diff；对着墙前后移，两路数值应明显升高
```

## 采集（Pi 上，每组 5~10 秒，车保持不动）

文件名关键词供 `dev/calibrate_front_adc.py` 分类，**必须照抄**：

| # | 文件名 | 姿态 |
|---|---|---|
| 1 | `正对墙居中位置.csv` | 车头正对墙，离墙 ~10~20cm（矫正的工作距离） |
| 2 | `正对墙.csv` | 车头正对墙，贴墙最近（冲墙撞停的距离，别撞坏） |
| 3 | `正对墙最远.csv` | 车头正对墙，离墙 80cm~1m（信号偏弱） |
| 4 | `左偏居中位置.csv` | 车头向左转 ~20°，离墙 ~10~20cm |
| 5 | `右偏居中位置.csv` | 车头向右转 ~20°，离墙 ~10~20cm |

```bash
python3 dev/ir_tool.py collect --hz 50 --out data/正对墙居中位置.csv   # Ctrl+C 结束
```

注意：`左偏/右偏` 不带「居中位置」会被归到 far 组、不进 diff 阈值建模；
`正对墙` 贴墙组用于重算 `REENTRY_APPROACH_TOUCH_SIGNAL`。

## 重算与写回

```bash
python3 dev/calibrate_front_adc.py
```

- 输出 `data/front_adc_processed.csv`（滤波明细）、`data/front_adc_summary.csv`
  （分组统计 + alignment_usable 可用性判断）、`data/front_adc_model.csv`（建议值）。
- 要求「左偏 / 正对居中 / 右偏」三组区间不重叠，否则报错重采。
- 核对后写回 config.py：`IR_ALIGNMENT_DIFF_LOW / DIFF_HIGH / SIGNAL_MIN`；
  贴墙阈值 `REENTRY_APPROACH_TOUCH_SIGNAL` 取「正对墙(贴墙) signal_p99 与
  居中位置 signal_p99 的中点」。
- CSV 拷回 PC 后用 Excel 看完先关掉再跑 calibrate（文件被占用会读取失败）。
